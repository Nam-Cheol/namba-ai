# v1.0.1 릴리즈 노트

v1.0.0 이후 변경 사항입니다.

## 사용자에게 보이는 변경

- `namba init`의 진행 상태/결과 표시를 Bubble Tea v2와 Lip Gloss v2 기반 TUI로 전환했습니다. 기존 선택 흐름은 유지하면서 interactive wizard는 AltScreen에서 model-driven `Init`/`Update`/`View` 구조로 동작하고, 종료 후에는 생성/스킵 파일 요약을 plain text로 출력합니다. (SPEC-068, PR #102, 1c75a35)
- CI와 non-TTY 환경에서는 기존처럼 non-interactive fallback 경로를 유지합니다. init flow의 domain logic과 TUI rendering logic을 분리해 console log 중심 UI 구현을 피했습니다. (SPEC-068, 1c75a35)

## 수정

- text input 단계에서 `q`를 입력하려 할 때 wizard가 종료되던 문제를 수정했습니다. 이제 `q`는 text step에서는 입력값으로 들어가고, non-text step에서만 quit shortcut으로 동작합니다. (PR #102 review, 35ac2d2)
- 다국어 입력에서 backspace가 UTF-8 byte를 잘라 invalid string을 만들 수 있던 문제를 수정했습니다. 이제 마지막 rune 단위로 삭제하며 Korean 입력 회귀 테스트로 검증합니다. (PR #102 review, 35ac2d2)
- Go standard library 취약점 스캔 실패를 해소하기 위해 toolchain을 `go1.26.4`로 올리고 README/renderer 문구를 맞췄습니다. `govulncheck` 결과는 `No vulnerabilities found.`입니다. (bde7571)

## 문서 및 워크플로

- SPEC-068 산출물과 readiness/review 문서를 `.namba/specs/SPEC-068/`에 추가하고 manifest와 project docs를 갱신했습니다. (SPEC-068, 1c75a35)
- README 다국어 bundle과 renderer contract에서 Go toolchain 표기를 취약점 수정 버전에 맞게 갱신했습니다. (bde7571)

## 내부 정비

- `internal/namba/init_tui.go`에 Bubble Tea v2 model을 추가하고, `init_command`, `update_command`, `self_update_command`, `execution` 경로의 상태 표시를 TUI-friendly summary로 정리했습니다. (1c75a35)
- `internal/namba/init_tui_test.go`에 Bubble Tea model update, non-TTY fallback, `q` text input, multibyte backspace 회귀 테스트를 추가했습니다. (1c75a35, 35ac2d2)
