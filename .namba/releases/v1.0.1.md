# v1.0.1 릴리즈 노트

v1.0.0 이후 변경 사항입니다.

## 사용자에게 보이는 변경

- SPEC-068 Bubble Tea TUI 적용 (SPEC-068, 1c75a35)
  - `namba init` interactive mode uses Bubble Tea v2 with a model-driven `Init`, `Update`, and `View`.
  - `namba init` interactive mode uses Lip Gloss v2 for all TUI visual styling.
  - `namba init` interactive mode runs in Bubble Tea AltScreen.
  - `namba init` supports up, down, left, right, Enter, Esc, and q navigation.
  - `namba init` preserves the current selection flow, defaults, validation, generated files, and manifest behavior.
  - `namba init --yes`, CI, and non-TTY flows keep a non-interactive fallback.
  - After the interactive TUI exits, stdout prints a plain text summary of created and skipped files.
  - `namba update` presents progress and final result state through TUI rendering when interactive, without becoming a wizard.
  - `namba update` preserves release download, checksum verification, binary extraction, replacement, Windows scheduling, and error semantics.
  - `namba regen` presents progress and final result state through TUI rendering when interactive, without becoming a wizard.
  - `namba regen` preserves managed-output ownership rules and session-refresh guidance.
  - Domain init logic is separated from TUI rendering logic.
