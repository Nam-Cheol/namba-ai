# v1.0.0 릴리즈 노트

v0.5.18 이후 변경 사항입니다.

## 사용자에게 보이는 변경

- NambaAI 하네스 평가 흐름을 1.0 품질 게이트로 격상했습니다. `namba eval`, `namba report`, 점수표, 기준선 비교, 스키마 검증이 함께 동작하며 회귀를 더 명확하게 보여줍니다. (SPEC-056, SPEC-062, db15268, caea420)
- `namba report` 관측 리포트 명령을 추가해 실행 증거와 프로젝트 상태를 JSON/문서 흐름에서 재사용할 수 있게 했습니다. (SPEC-059, #91, 56d685a)
- `namba init` 온보딩을 언어 선택 우선 흐름으로 바꾸고, 한국어/영어/일본어/중국어 사용자가 첫 화면부터 이해할 수 있도록 정리했습니다. (SPEC-064, 9c23e9f)
- `namba --version` 및 버전 advisory를 추가해 설치된 CLI 버전, 최신 릴리즈 상태, 다음 업데이트 행동을 더 분명하게 확인할 수 있게 했습니다. (SPEC-065, efc819a)
- README와 시작 가이드에 Mermaid 기반 문서 흐름, 실행 가능한 예제, 검증 가이드를 보강했습니다. (SPEC-060, c375d31, 2cca440, b70fc95, 9702bc6)

## 수정

- 큐와 원격 핸드오프의 local fallback 판정을 좁히고, 연속 처리와 auto-land 가드를 보강해 실패 분류가 과도하게 진행을 밀어붙이지 않도록 했습니다. (SPEC-061, ae18936, e17712f, cc28857, feb15a4, 55f9c5a, cbeb1ea)
- eval 기준선 갱신, mention routing, guardrail matcher, 리뷰 피드백 반영 테스트를 강화해 하네스 평가가 더 결정적으로 동작하도록 했습니다. (SPEC-056, 9115fcc, c8a4f92, 1a7fbd8, 8ea7d32, 8864812, 98a7451, 1e1dfe1, 72b808f)
- release GitHub Actions에서 Windows runner를 고정하고 release action 설정을 갱신했습니다. (596681f)
- gitleaks fixture와 eval baseline 관련 false positive를 줄였습니다. (9cfbfff, 76f6714)
- sync advisory 중복 방지 회귀 테스트를 추가했습니다. (b9e80ef)

## 문서 및 워크플로

- 로컬 품질 게이트와 CI 품질 게이트를 강화하고, Python unittest, gofmt, go vet, Go 테스트, harness eval, schema validation, race test, staticcheck, govulncheck, coverage threshold를 한 흐름으로 문서화했습니다. (15de3b8, f2c0597, d13272a)
- 관리 프로젝트 검증 가이드를 분리하고 최종 보고 형식이 검증 증거를 보존하도록 정리했습니다. (SPEC-063, e6cc8ad, 5c45ea2)
- 생성 지침 계약과 조건부 승인 정책을 강화해 command-entry skill과 Codex guardrail의 역할, 승인 요청, 출력 계약을 더 명확하게 했습니다. (SPEC-066, a6dce3c, 03aa109, 42c30fd)
- Namba workflow guidance와 repo-local skill/agent 지침을 최신 Codex-native 경계에 맞춰 갱신했습니다. (3e3f421, 597f819, f294298)
- SPEC-055부터 SPEC-067까지 계획, 수용 기준, 리뷰, 하네스 sidecar 자료를 `.namba/specs/`에 보존했습니다. (4f7173a, b401a30, c6e02f2)

## 내부 정비

- `internal/namba/namba.go` 중심의 큰 구현을 app, commands, init, project, run, sync, report, eval, config 등 더 작은 모듈로 분해했습니다. 동작 보존 체크리스트와 characterization test로 회귀 위험을 낮췄습니다. (SPEC-067, ff17c03)
- README 렌더러와 문서 컴포넌트를 분리하고 다국어 README/guide 동기화 테스트를 강화했습니다. (SPEC-060, SPEC-063, internal/namba/readme_components.go, internal/namba/readme_sync_test.go)
- evidence/report/eval JSON 스키마와 fixture를 추가해 `execution-evidence/v1`, `namba-eval-*`, `namba-report/v1`, `queue-runner-evidence/v1` 계약을 검증 가능하게 했습니다. (SPEC-062, internal/namba/testdata/schemas/, internal/namba/schema_contract_test.go)
- offline CLI E2E workflow fixture test를 추가해 네트워크 없는 환경에서도 핵심 명령 흐름을 검증합니다. (5a92166)
- `assets/images/namba-ai-hero.png`를 최적화하고 생성 산출물 manifest 및 project codemap을 갱신했습니다. (.namba/manifest.json, .namba/project/structure.md)
